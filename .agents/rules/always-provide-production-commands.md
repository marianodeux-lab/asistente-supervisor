# Instrucción Permanente: Comandos de Subida a Producción

Al finalizar CADA interacción o respuesta con cambios de código o datos, proporcionar siempre al usuario en un bloque de código claro y listo para copiar los comandos para subir a producción (GitHub / Vercel):

```bash
git add .
git commit -m "..."
git push origin main
```
O la opción de ejecutar el script automatizado:
```cmd
.\ACTUALIZAR_PORTAL.bat
```
